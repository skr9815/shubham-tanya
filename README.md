# Shubham & Tanya — Wedding Invitation 💍

A React (Vite) wedding invitation website.

## Run locally

```bash
npm install
npm run dev
```

## Customize

All wedding details (date, events, venue, contacts, RSVP email, story) live in [`src/config.js`](src/config.js).

## Build

```bash
npm run build   # outputs to dist/
```
